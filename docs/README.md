# Hiroi Downloader guide

This guide explains every feature and how to use it. `hiroi --help`,
and `--help` after any command, list every option, and
`hiroi search WORDS` finds a command, an option, or a setting by what
it does.

1. [Getting started](getting-started.md): building, the first
   download, the background service, and the browser extension.
2. [Downloading](downloading.md): connections, mirrors, checksums,
   resuming, speed limits, streams, video sites, Metalink, FTP, SFTP,
   and BitTorrent.
3. [Grabbing pages](grabbing.md): everything a web page offers, from
   the command line.
4. [Keeping downloads in order](organizing.md): queues, schedules,
   categories, groups, and smart folders.
5. [The browser extension](browser.md): menus, the grab page, media
   detection, the video button, and capturing browser downloads.
6. [Network and privacy](network-and-privacy.md): proxies, binding to
   a VPN, the IP filter, and what a download gives away.
7. [Settings and search](settings.md): the settings file, every
   setting, and finding things.
